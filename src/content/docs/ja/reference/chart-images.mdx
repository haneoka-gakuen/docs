サイトのダウンロードと同じ音符アトラス、スライド、ジャケット、アイコン、フォント、レイアウトを使います。入力を固定するには release を指定します。ブラウザーサービスで PNG を生成し、SVG には同じ PNG を内包します。譜面全体を列に配置します。端末での出力は[ローカル計算](/ja/guides/local-computation/)を参照してください。ETag には release、画像設定、内容ハッシュが入ります。
