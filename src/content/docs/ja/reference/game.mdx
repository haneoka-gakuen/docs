URL ごとにゲーム地域を指定してください。64 ビット ID は十進文字列のまま扱い、accountId、profileId、songId、challengeId を区別します。保存済みガチャ情報はカタログ、保存済みお知らせは /api/v1/announcements を使います。このページではゲームの契約を追加し、取得した全フィールドを保持します。[ゲーム API ガイド](/ja/guides/game-api/)に手順を掲載しています。
