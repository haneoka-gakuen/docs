---
title: サイト・スクリプト・Agent からのゲームデータ取得
description: 用途に合った API、地域、ID、レスポンス形式を選びます。
---

`GET https://haneoka.org/api/v1` から始めます。OpenAPI、リリース一覧、リソースカタログ、ゲーム機能一覧、ローカル計算モジュールへのリンクがあります。公開読み取りは GET/HEAD。エラー形式は `{ "error": { "code", "message", "requestId" } }`。HEAD は本文を返しません。

| 用途 | API |
| --- | --- |
| ゲーム資料とルール | `/api/v1/servers/{server}/catalog` から各リソース・ビュー・リレーションへ |
| 単体・一括・全件 | `/api/v1/{resource}/{id}`、繰り返し `id`、`nextCursor` が null になるまでページ取得 |
| 音声・画像・モデル・フォント・素材情報 | レスポンスの `/assets/`、`/runtime/` と素材記述。release を固定 |
| 譜面と統計 | `songs/{id}` の `difficulty[].file` と `song-meta/{id}` |
| プロフィール・一括取得・お気に入り・カード | `/api/v1/players/{profileId}?region={region}`、`/api/v1/players?accountId=…&region={region}`、`/api/v1/players/favorites?accountId={accountId}&region={region}`、`/api/v1/players/{profileId}/cards/{page}.png?region={region}` |
| 楽曲・イベント・チャレンジ・アリーナ順位 | `/songs/{songId}/ranking`、`/events/{eventId}/ranking?rank=1&rank=100`、`/events/challenges/{challengeId}/ranking`、`/arena/seasons/{seasonId}/ranking?start=1&end=100` |
| イベント編成・アリーナ編成傾向 | `/events/{eventId}/decks/{accountId}`、`/arena/seasons/{seasonId}/songs/{songId}/decks` |
| サークル詳細・名前検索 | `/circles/{circleId}`、`/circles?name=…`。`memberRange`、`joinRule`、`playStyle` も指定可能 |
| 保存済みガチャと商品 | `/api/v1/gacha/{gachaId}?server={server}` の `rates`、`featured`、`drawOptions`、確定枠・選択ルール |
| 商品と選択ピックアップの提供割合 | `/api/v1/gacha/{gachaId}/rates?productId=…&pickupId=…&region={region}` |
| 保存済み・ゲーム内お知らせ | `/api/v1/announcements?server={server}&locale={locale}`、`/api/v1/announcements/views/live?region={region}`、`/announcements/{announcementId}/live` |
| イベント予定・ボーダー・収集状態 | `/api/v1/events/views/live?region={region}`、`/events/views/current`、`/events/{eventId}/snapshots`、`/events/{eventId}/snapshots/latest`、`/events/{eventId}/challenges` |
| チャレンジのスナップショット・お知らせの版 | `/events/{eventId}/challenges/{challengeId}/ranking`、`/announcements/{announcementId}/revisions` |
| 非公開 Box・所持状況・作業領域・ガチャ履歴 | [アカウント同期](/ja/auth/) |
| 編成探索・評価・育成分析・譜面画像 | [ローカル計算](/ja/guides/local-computation/) |

`server` は jp/intl、`region` は jp/tw/en/kr、`locale` は表示言語です。64 ビット ID は文字列のまま扱います。profileId と accountId、challengeId と songId は別です。同じ地域の ID を使用してください。

```js
import { createGameClient } from "https://haneoka.org/tools/api-client.js";
const game = createGameClient({ region: "jp" });
const ranking = await game.songRanking("100001");
for (const row of ranking.players ?? []) console.log(row.playerData?.profileId, row.score);
const profiles = await game.profiles(accountIds);
const circle = await game.circles({ name: circleName, joinRule: "AUTO" });
```

配列は `accountId=1&accountId=2`、`rank=1&rank=100`、`pickupId=1&pickupId=2` のようにキーを繰り返します。最大 100 件です。スカラーの重複・未知のパラメーターは 400。[参照](/ja/reference/game/)で必須値を確認してください。楽曲順位は応答順を保持し、欠けた順位をゼロで埋めません。イベント保存時は `stale`、`frozen`、`parts` と取得時刻を残します。429/503 は `Retry-After` と指数バックオフに従います。ゲームの OpenAPI は `/api/v1/openapi.json` です。

セーブの取得は `GET /api/v1/players/{profileId}/save.gz?server={saveServer}`。サーバーまたはローカルスクリプトから `X-Game-Application-Key` を付け、アプリはそのセーブへの明示的なアクセス許可を持つ必要があります。profileId はセーブ最上位の _profileId で、アカウント ID とは別です。saveServer は jp/intl。最大 8 MiB の `application/gzip` を `.json.gz` として保存します。HTTP `Content-Encoding` は付きません。許可がなければ 404。キーはサーバーに保存します。羽丘のアカウント内データには既存の同期 API と羽丘のセッションを使います。
