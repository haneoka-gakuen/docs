在[表情製作工具](https://haneoka.org/zh-CN/stamp-maker/)中，選擇本站表情圖片，新增和排版自己的文字，再下載合成後的 PNG。開啟網頁即可使用，無需安裝創作工程。

## 製作第一張表情

1. 開啟**選擇表情**。
2. 在彈窗中選擇日文、英文、繁體中文、簡體中文、韓文或**無字**，再點選一張表情卡片。選擇後彈窗關閉，圖片進入預覽區。
3. 在**文字**中輸入短句，選擇排版方向、字型、文字大小和顏色。
4. 在預覽中拖動文字調整位置。需要精確控制時，展開**位置與描邊**，調整座標、旋轉和描邊。
5. 選擇**匯出尺寸**，點選**匯出 PNG**。

手機上，選圖入口和圖片預覽保持可見，編輯區單獨滾動。在編輯區內滑動即可找到後續設定。編輯會自動儲存為當前瀏覽器的本地草稿。重新開啟工具時會恢復圖片和文字圖層；下載的 PNG 儲存合成後的畫面。

## 選擇圖片語言與無字版本

新建表情預設使用**無字**。選擇原圖語言時，預設跟隨當前頁面語言；手動選擇其他語言後會保留該選擇。點選彈窗右上角關閉按鈕或按 Escape 可關閉選擇器。

五種語言和**無字**位於**選擇表情**彈窗中的同一組選項。它們切換要編輯的圖片版本，頁面介面的語言保持原樣。例如，中文介面中也可以選英文原圖。

卡片標註實際使用的圖片版本。部分素材由多個語言共用，會保留同一張原圖。**無字**顯示當前可用、經過稽核的素材，因此它的列表可能與各語言原圖不同。選回一種語言即可繼續使用帶有原文字的圖片。

新增文字時，底圖中的原有文字仍屬於圖片。修改文字輸入框會編輯你新新增的內容。要替換已有文字，可以選無字素材，或使用下文的[文字背景](#用文字背景覆蓋已有文字)。

工具從本站表情目錄選圖，不提供圖片上傳。字型欄旁的匯入按鈕用於匯入本地字型。

## 用圖片和文字圖層安排畫面

每個文字層分別儲存內容、字型及可用字重、顏色、描邊、位置、旋轉、橫豎排和背景。圖片上需要多處文字時，為每個區域建立一層。

| 控制元件 | 操作 |
| --- | --- |
| **圖層** | 根據編號和內容片段選擇圖層，列表優先顯示靠前的圖層。 |
| **新增文字** | 建立並選中一個空文字層，沿用當前文字樣式，背景預設關閉。 |
| **圖層操作 → 複製文字層** | 複製當前層的文字與樣式，包括背景；副本稍微錯開，方便繼續擺放。 |
| **圖層操作 → 刪除文字層** | 刪除當前文字層。工具至少保留一個文字層。 |
| **上移一層／下移一層** | 將當前層在繪製順序中向前或向後移動一層。 |
| **重置所選圖層** | 重置文字樣式並保留內容；選擇圖片層時，恢復居中、100% 縮放和零旋轉。 |

從**圖層**中選擇**表情圖片**，即可移動、旋轉和縮放圖片。圖片縮放範圍為 10%～300%；100% 按有效原圖尺寸放入 512 畫素的正方形畫布，小原圖居中並留透明邊。圖片可與文字一起上移或下移，預覽與 PNG 使用相同層序。工具保留一個圖片層和至少一個文字層。

最多可建立 12 個文字層，每個文字框最多 500 個字元。在預覽中點選文字區域可以選中並拖動該層；區域重疊時，優先選中上面的層。要調整被遮住的文字，從**圖層**下拉框選擇它。

展開**位置與描邊**可精確設定位置。水平和垂直座標使用畫布百分比，旋轉使用角度。預覽獲得焦點後，方向鍵每次移動一個百分點，按住 Shift 則移動五個百分點。**圖層居中**將當前層的定位點放到畫布中央。

## 橫排、豎排與列方向

排版方向有**橫排**、**豎排 ←**和**豎排 →**。箭頭表示列的排列方向：向左時從右側開始排下一列，向右時從左側開始排下一列。

豎排中，換行會另起一列，較長內容也會分列。中日韓文字保持直立，拉丁文字連續片段側轉，一到兩位 ASCII 數字可以橫向放在一個字格內，標點隨豎排列調整位置或旋轉。各文字層可以使用不同方向。

預覽、點選命中和 PNG 使用同一套排版。混合不同文字或輸入較長內容時，結合預覽調整字號和位置。

## 選擇字型和角色代表色

從**字型**中選擇字型，等待載入完成後匯出。字型選項的用途和可用字重如下：

| 字型 | 用途與字重 |
| --- | --- |
| **YurukaStd** | 參考的 Sekai 表情工具使用的字型，提供的字型為 UB，真實字重 900。 |
| **SSFangTangTi** | Sekai 工具使用的上首方糖體，提供的字重為 400。 |
| **Roboto** | 可變字重 100–900。 |
| **思源黑體 SC／TC／JP／KR** | 各地區 CJK 無襯線字型，可變字重 100–900。 |
| **思源宋體 SC／TC／JP／KR** | 各地區 CJK 襯線字型，可變字重 200–900。 |
| **原作執行時 UI · Pretendard SemiBold** | Our Notes 執行時 UI 字型，真實字重 600。 |

支援可變字重的字型會顯示**字重**控制元件，初始使用最粗的可用字重。固定字型沿用自身已有字重。字型覆蓋的字元範圍各有不同；遇到缺字時，可選擇對應地區的字型。

Sekai 字型說明參考工具的文字樣式，Pretendard 說明執行時 UI 的字型用途。Our Notes 原圖中的表情文字已經繪製在圖片裡，其製作用字型尚未確認；這些選項不代表已確認原圖文字使用了同一字型。

點選字型欄旁的**匯入本地字型**，可從裝置選擇 WOFF2、WOFF、TTF 或 OTF 檔案。字型按檔名加入選項，在當前頁面使用，單個檔案上限為 32 MiB。重新進入工具後，需要再次匯入。

**文字顏色**選單提供角色名字、頭像和實際代表色色樣。表情關聯的角色可以提供初始顏色，也可以自由選擇其他角色，或切換到**自定義顏色**。每個文字層分別儲存自己的顏色選擇。

## 用文字背景覆蓋已有文字

為當前層展開**位置與描邊 → 文字背景**，啟用背景後，選擇角色色或自定義背景色，並調整：

- **背景不透明度**：100% 為不透明，降低後可透出底圖。
- **背景內邊距**：文字實際字形及描邊之外的留白，預設 0，邊緣貼近文字。
- **背景圓角**：背景矩形四角的圓弧大小。

背景跟隨該層的位置和旋轉。將它移動到舊文字區域，結合預覽檢查覆蓋範圍。它作為文字層的矩形繪製在底圖上，原始圖片仍保留在下方。切換回**無背景**即可去掉矩形。

描邊顏色和寬度也在這一折疊區內。預覽中的選中框用於編輯定位，下載的 PNG 不包含這個框。

## 儲存和恢復本地草稿

編輯後，工具會在當前瀏覽器儲存所選表情、圖片語言、圖片的位置與縮放、各文字層樣式及繪製順序。重新開啟工具時，等待素材載入即可恢復。草稿選單也可恢復上次儲存的內容或清除本地草稿。

草稿儲存在這臺裝置的瀏覽器裡。清除瀏覽器站點資料會刪除它；它不會自動同步到其他裝置。自己匯入的字型檔案需要重新匯入，字型缺失時會提示。原表情資源不可用時，檢查圖片提示並重新選擇素材，文字層仍可繼續編輯。PNG 匯出儲存最終合成圖，草稿儲存可編輯設定。

## 匯出正方形 PNG

**匯出尺寸**提供 128 × 128、256 × 256、384 × 384 和 512 × 512 四檔。畫布始終為正方形，最大下載尺寸固定為 512 × 512。

346 × 398 的小原圖預設按該尺寸居中放在 512 × 512 畫布上，四周留透明邊；較大原圖會縮小以放入畫布。構圖時可主動調整**圖片縮放**，放大圖片會改變畫面佔比，原始細節仍取自來源圖片。

較小檔位會整體縮小圖片、文字、描邊和背景。匯出開始時會取得所有圖層的設定和順序，按同一繪製邏輯合成並保留透明部分。預覽選中框不進入 PNG；下載的檔案儲存合成後的圖片。

## 示例：頂部短句與側邊豎排

1. 在**選擇表情**中選擇一個當前可用的無字素材。
2. 在第一層寫一句短句，使用橫排，選擇字型和角色色，將它拖到角色上方。
3. 點選**新增文字**，輸入側邊補充文字，切換到**豎排 ←**，再放到角色旁邊。第一層保持原樣。
4. 如果兩個區域重疊，從**圖層**選擇需要的層，用**上移一層／下移一層**調整覆蓋順序。
5. 匯出**512 × 512 px**作為主檔案；需要小尺寸表情時，再選較小檔位下載。

## 常見調整

| 現象 | 處理方法 |
| --- | --- |
| 圖片載入失敗 | 點選**重試**，或重新開啟選擇器換一張可用圖片。 |
| 字型載入失敗 | 重試或換一種字型，載入完成後再匯出。 |
| 某個字缺失或外觀不同 | 換成覆蓋該文字的地區字型，或匯入合適的本地字型。 |
| 文字超出畫面 | 選中該層，縮小字號、調整位置，或使用**圖層居中**。 |
| 點不到下方文字 | 從**圖層**選擇，或調整圖層順序。 |
| 原圖舊文字仍可見 | 使用無字素材，或把不透明文字背景放到舊文字區域。 |
| 選單沒有更大的尺寸 | 選擇**512 × 512 px**，即最大構圖尺寸。 |
