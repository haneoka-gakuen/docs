[스탬프 메이커](https://haneoka.org/ko/stamp-maker/)로 사이트의 스탬프 이미지에 원하는 글자를 넣을 수 있습니다. 이미지 버전을 고르고, 텍스트 레이어를 하나 이상 배치하고, 조합한 결과를 PNG로 내려받습니다. 도구는 브라우저에서 동작하며 아무것도 설치할 필요가 없습니다.

## 첫 스탬프 만들기

1. **스탬프 선택**을 엽니다.
2. 선택 화면에서 일본어, 영어, 번체 중국어, 간체 중국어, 한국어 또는 **글자 없음**을 고릅니다. 스탬프 카드를 누르면 그것을 쓰고 선택 화면이 닫힙니다.
3. **글자**에 짧은 문구를 입력합니다. 쓰기 방향, 글꼴, 크기, 색을 고릅니다.
4. 미리보기에서 글자를 끌어 배치합니다. 정확한 위치, 회전, 테두리는 **위치 및 테두리**에서 설정합니다.
5. **내보내기 크기**를 고른 뒤 **PNG 내보내기**를 누릅니다.

휴대폰에서는 이미지 선택과 미리보기가 그대로 보이고 편집 패널만 스크롤됩니다. 나머지 조작은 패널 안에서 스크롤하세요. 편집 내용은 이 브라우저에 로컬 초안으로 저장됩니다. 도구를 다시 열면 이미지와 텍스트 레이어가 돌아오며, PNG를 내려받으면 조합된 모습이 저장됩니다.

## 이미지와 그 언어 고르기

새로 만들 때는 **글자 없음**으로 시작합니다. 언어 버전을 고를 때 기본값은 페이지 언어를 따르며, 직접 고른 언어는 유지됩니다. 선택 화면은 오른쪽 위 버튼이나 Escape로 닫습니다.

언어와 **글자 없음**은 **스탬프 선택** 안의 같은 선택기에 있는 선택지입니다. 이는 편집할 이미지를 고르는 것이며 화면 언어는 바뀌지 않습니다. 예를 들어 화면은 중국어로 두고 영어 스탬프를 쓸 수 있습니다.

카드에는 실제 이미지 버전이 표시됩니다. 언어 사이에 공유되는 이미지도 있으며 원래 아트워크를 유지합니다. **글자 없음**에는 검토된 사용 가능한 이미지가 나열되므로 언어별 목록과 다를 수 있습니다. 원래 글자가 있는 이미지로 돌아가려면 다른 언어를 고르세요.

글자를 넣어도 사이트의 원본 이미지는 그대로입니다. 글자 필드에서 편집하는 것은 새로 넣는 문구입니다. 기존 글자를 바꾸려면 글자 없는 이미지를 고르거나 [텍스트 배경](#텍스트-배경으로-기존-글자-가리기)을 쓰세요.

이미지는 사이트의 스탬프 카탈로그에서 가져옵니다. 이미지 업로드는 받지 않습니다. 로컬 글꼴은 **글꼴** 옆의 명령으로 가져올 수 있습니다.

## 이미지와 텍스트 레이어 다루기

텍스트 레이어마다 문구, 글꼴과 쓸 수 있는 굵기, 색, 테두리, 위치, 회전, 쓰기 방향, 선택적 배경을 따로 가집니다. 이미지의 여러 곳에 문구를 넣을 때는 레이어를 나누세요.

| 조작 | 하는 일 |
| --- | --- |
| **레이어** | 번호와 문구로 레이어를 고른다. 목록은 앞쪽 레이어부터 보여 준다. |
| **텍스트 추가** | 현재 텍스트 스타일로 빈 레이어를 만들어 고른다. 배경은 꺼져 있다. |
| **레이어 작업 → 레이어 복제** | 고른 레이어의 문구와 스타일을 배경까지 복사한다. 원본과 구분하기 쉽게 살짝 비켜 놓는다. |
| **레이어 작업 → 레이어 삭제** | 고른 텍스트 레이어를 지운다. 텍스트 레이어는 최소 하나 남는다. |
| **앞으로 이동 / 뒤로 이동** | 고른 레이어의 그리기 순서를 한 칸 옮긴다. |
| **선택한 레이어 초기화** | 문구는 두고 고른 텍스트 스타일을 되돌린다. 또는 이미지를 가운데, 크기 100%, 회전 0으로 되돌린다. |

이미지를 옮기거나 회전하거나 크기를 바꾸려면 **레이어**에서 **스탬프 이미지**를 고르세요. 이미지 크기는 10%~300%이며, 100%는 512픽셀 정사각형 캔버스 안에서의 실제 원본 크기입니다. 작은 원본은 투명한 여백과 함께 가운데에 놓입니다. 이미지는 텍스트 레이어 사이에서 앞뒤로 옮길 수 있고, 미리보기와 내보내는 PNG는 같은 순서를 씁니다. 이미지 레이어는 하나, 텍스트 레이어는 최소 하나가 남습니다.

에디터는 텍스트 레이어를 12개까지, 텍스트 필드마다 500자까지 다룹니다. 미리보기에서 텍스트 영역을 누르면 그 레이어를 골라 끌 수 있습니다. 영역이 겹치면 위쪽 레이어가 클릭을 받으므로, 아래의 것은 **레이어**에서 고르세요.

정확히 배치하려면 **위치 및 테두리**를 엽니다. 가로·세로 위치는 이미지 캔버스에 대한 백분율, 회전은 도 단위입니다. 미리보기에 포커스가 있을 때 화살표 키로 고른 레이어를 1포인트, Shift를 누르고 있으면 5포인트 옮깁니다. **레이어 가운데 정렬**은 기준점을 가운데에 둡니다.

## 가로쓰기와 세로쓰기

쓰기 방향 조작에는 **가로쓰기**, **세로쓰기 ←**, **세로쓰기 →**가 있습니다. 화살표는 열의 순서를 나타내며, 왼쪽 방향은 오른쪽에서, 오른쪽 방향은 왼쪽에서 시작합니다.

세로쓰기에서는 줄바꿈으로 다음 열을 시작합니다. 긴 열은 다음 열로 넘어갑니다. CJK 문자는 바로 서고, 라틴 문자열은 옆으로 눕고, 한두 자리 ASCII 숫자는 한 칸에 바로 서서 들어갈 수 있으며, 문장 부호는 열에 맞게 위치나 방향이 바뀝니다. 레이어마다 방향을 다르게 줄 수 있습니다.

미리보기, 포인터 선택, PNG는 같은 텍스트 배치를 씁니다. 특히 여러 문자 체계를 섞거나 문구가 길 때는 미리보기를 보면서 글꼴 크기와 위치를 조정하세요.

## 글꼴과 캐릭터 색

**글꼴**에서 글꼴을 고르고 불러오기가 끝난 뒤 내보내세요. 쓸 수 있는 글꼴의 용도는 다음과 같습니다.

| 글꼴 | 용도와 쓸 수 있는 굵기 |
| --- | --- |
| **YurukaStd** | 참고한 세카이 스티커 도구가 쓰는 글꼴. 제공되는 것은 UB, 굵기 900. |
| **SSFangTangTi** | 세카이 도구의 상서우 팡탕체. 제공되는 굵기는 400. |
| **Roboto** | 가변 굵기 100~900. |
| **Noto Sans SC / TC / JP / KR** | 지역별 CJK 고딕 계열, 가변 굵기 100~900. |
| **Noto Serif SC / TC / JP / KR** | 지역별 CJK 명조 계열, 가변 굵기 200~900. |
| **게임 내 UI · Pretendard SemiBold** | Our Notes 게임 내 UI 글꼴, 실제 굵기 600. |

가변 글꼴에서는 **글꼴 굵기** 조작이 나오며 가장 굵은 값으로 시작합니다. 고정 글꼴은 제공된 굵기를 유지합니다. 수록 글자는 글꼴마다 다르니, 글자가 빠지면 알맞은 지역 글꼴을 고르세요.

세카이 글꼴은 참고한 도구의 서체를, Pretendard는 게임 내 UI 서체를 나타냅니다. Our Notes 원래 스탬프 글자는 이미지의 일부이며, 만들 때 쓴 글꼴은 밝혀지지 않았습니다. 따라서 어느 이름도 그 박혀 있는 글자의 서체를 뜻하지 않습니다.

글꼴 칸 옆의 **로컬 글꼴 가져오기**로 기기의 WOFF2, WOFF, TTF, OTF를 불러올 수 있습니다. 가져온 글꼴은 파일 이름으로 표시되고 현재 페이지에서 쓰입니다. 글꼴 파일 하나는 32 MiB까지입니다. 그 글꼴을 쓰는 초안을 복원할 때는 파일을 다시 가져오세요.

**글자 색**에는 이름, 초상, 실제 색 견본이 있는 캐릭터 프리셋이 있습니다. 스탬프와 관련된 캐릭터 색이 처음 색이 될 수 있으며, 목록의 어떤 캐릭터든 **사용자 지정 색**이든 고를 수 있습니다. 색 선택은 고른 텍스트 레이어마다 따로입니다.

## 텍스트 배경으로 기존 글자 가리기

고른 레이어의 **위치 및 테두리 → 텍스트 배경**을 열고 배경을 켭니다. 캐릭터 색 프리셋이나 사용자 지정 배경색을 고르고 다음을 조정합니다.

- **배경 불투명도**: 100%면 불투명하고, 낮추면 이미지가 비칩니다.
- **배경 여백**: 실제 글자와 테두리 바깥의 여백. 0에서 시작해 가장자리에 딱 맞습니다.
- **배경 모서리**: 사각형 모서리의 둥글기.

배경은 그 레이어의 위치와 회전을 따릅니다. 원래 글자 위에 놓고 가리려는 범위를 덮는지 확인하세요. 이는 텍스트 레이어의 사각형이며, 아래의 원본 이미지는 그대로입니다. **배경 없음**으로 돌리면 사각형이 사라집니다.

테두리 색과 두께도 같은 보조 패널에 있습니다. 미리보기의 선택 안내선은 편집 보조이며 내려받는 PNG에는 나오지 않습니다.

## 로컬 초안 저장과 복원

편집하면 고른 스탬프, 이미지 언어, 이미지 위치와 크기, 텍스트 레이어 스타일과 그리기 순서가 이 브라우저에 저장됩니다. 도구를 다시 열고 리소스 불러오기를 기다리면 초안이 돌아옵니다. 초안 메뉴에서 마지막으로 저장한 내용을 복원하거나 로컬 초안을 지울 수도 있습니다.

초안은 이 기기의 브라우저에 속합니다. 사이트 데이터를 지우면 사라지며 다른 기기와 동기화되지 않습니다. 글꼴이 없다는 알림이 나오면 로컬 글꼴 파일을 다시 가져오세요. 원래 스탬프 리소스를 쓸 수 없으면 이미지 알림을 확인하고 다른 스탬프를 고르세요. 텍스트 레이어는 편집 가능한 채로 남습니다. PNG 내보내기는 조합된 이미지를, 초안은 편집 가능한 설정을 저장합니다.

## 정사각형 PNG 내보내기

**내보내기 크기**는 128 × 128, 256 × 256, 384 × 384, 512 × 512픽셀입니다. 모든 조합은 같은 정사각형 캔버스를 씁니다. 원본 이미지 크기와 관계없이 가장 큰 내려받기는 512 × 512입니다.

346 × 398 원본은 512 × 512 캔버스 가운데에 그 크기로 놓이고 주변은 투명한 여백이 됩니다. 큰 원본 이미지는 캔버스 안에 맞춰집니다. 조합할 때 **이미지 크기**로 일부러 키울 수 있지만, 키워도 원본의 세부가 늘어나지는 않습니다.

작은 크기로 내보내면 이미지, 글자, 테두리, 배경을 포함한 전체가 축소됩니다. 내보내기는 시작 시점의 모든 레이어 설정과 순서를 쓰고, 투명도를 유지하며, 선택 안내선은 넣지 않습니다. 내려받은 PNG에는 조합된 이미지가 저장됩니다.

## 예: 제목과 곁들임 글

1. **스탬프 선택**에서 쓸 수 있는 글자 없는 스탬프를 고릅니다.
2. 첫 레이어에 짧은 가로쓰기 제목을 씁니다. 글꼴과 캐릭터 색을 고르고 캐릭터 위로 끌어 놓습니다.
3. **텍스트 추가**로 곁들임 글을 입력하고 **세로쓰기 ←**를 고릅니다. 첫 제목은 그대로 두고 캐릭터 옆에 놓습니다.
4. 문구가 겹치면 **레이어**에서 원하는 레이어를 고르고 **앞으로 이동**이나 **뒤로 이동**을 씁니다.
5. 주 이미지는 **512 × 512 px**로, 작은 PNG가 필요한 앱에는 더 작은 크기로 내보냅니다.

## 조정이 필요할 때

| 보이는 상황 | 할 일 |
| --- | --- |
| 이미지를 불러오지 못한다 | **다시 시도**를 쓴다. 선택 화면을 다시 열어 다른 이미지를 골라도 된다. |
| 글꼴을 불러오지 못한다 | 다시 시도하거나 다른 글꼴을 고른다. 글꼴 불러오기가 끝나야 내보내기가 켜진다. |
| 글자가 빠지거나 다르게 보인다 | 그 문자 체계를 담은 글꼴을 고르거나 알맞은 로컬 글꼴을 가져온다. |
| 글자가 그림 밖으로 나간다 | 그 레이어를 골라 크기를 줄이거나 위치를 조정하거나 **레이어 가운데 정렬**을 쓴다. |
| 아래쪽 문구를 고를 수 없다 | **레이어**에서 고르거나 레이어 순서를 바꾼다. |
| 원래 글자가 그대로 보인다 | 글자 없는 이미지를 고르거나, 원래 글자 위에 불투명한 텍스트 배경을 놓는다. |
| 더 큰 내려받기 크기가 없다 | 최대 크기인 **512 × 512 px**를 고른다. |
