모든 URL에 게임 지역을 지정하세요. 64비트 ID는 십진 문자열로 유지하고 accountId, profileId, songId, challengeId를 구분하세요. 저장된 모집 정보는 카탈로그, 보관된 공지는 /api/v1/announcements를 사용합니다. 이 페이지는 게임 계약을 추가하고 제공된 모든 필드를 보존합니다. [게임 API 안내](/ko/guides/game-api/)에서 전체 흐름을 확인하세요.
