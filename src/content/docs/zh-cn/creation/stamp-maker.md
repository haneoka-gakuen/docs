在[表情制作工具](https://haneoka.org/zh-CN/stamp-maker/)中，选择本站表情图片，添加和排版自己的文字，再下载合成后的 PNG。打开网页即可使用，无需安装创作工程。

## 制作第一张表情

1. 打开**选择表情**。
2. 在弹窗中选择日文、英文、简体中文、繁体中文、韩文或**无字**，再点击一张表情卡片。选择后弹窗关闭，图片进入预览区。
3. 在**文字**中输入短句，选择排版方向、字体、文字大小和颜色。
4. 在预览中拖动文字调整位置。需要精确控制时，展开**位置与描边**，调整坐标、旋转和描边。
5. 选择**导出尺寸**，点击**导出 PNG**。

手机上，选图入口和图片预览保持可见，编辑区单独滚动。在编辑区内滑动即可找到后续设置。离开或刷新页面前先导出 PNG：可编辑图层保留在当前页面，下载的 PNG 保存合成后的画面。

## 选择图片语言与无字版本

五种语言和**无字**位于**选择表情**弹窗中的同一组选项。它们切换要编辑的图片版本，页面界面的语言保持原样。例如，中文界面中也可以选英文原图。

卡片标注实际使用的图片版本。部分素材由多个语言共用，会保留同一张原图。**无字**显示当前可用、经过审核的素材，因此它的列表可能与各语言原图不同。选回一种语言即可继续使用带有原文字的图片。

添加文字时，底图中的原有文字仍属于图片。修改文字输入框会编辑你新添加的内容。要替换已有文字，可以选无字素材，或使用下文的[文字背景](#用文字背景覆盖已有文字)。

工具从本站表情目录选图，不提供图片上传。字体栏旁的导入按钮用于导入本地字体。

## 用多个图层安排不同文字区

每个文字层分别保存内容、字体及可用字重、颜色、描边、位置、旋转、横竖排和背景。图片上需要多处文字时，为每个区域建立一层。

| 控件 | 操作 |
| --- | --- |
| **文字层** | 根据编号和内容片段选择图层，列表优先显示靠前的图层。 |
| **新增文字** | 建立并选中一个空文字层，沿用当前文字样式，背景默认关闭。 |
| **图层操作 → 复制文字层** | 复制当前层的文字与样式，包括背景；副本稍微错开，方便继续摆放。 |
| **图层操作 → 删除文字层** | 删除当前层。工具至少保留一层。 |
| **上移一层／下移一层** | 将当前层在绘制顺序中向前或向后移动一层。 |
| **重置当前文字样式** | 重置当前层样式，保留它的文字和其他图层。 |

最多可建立 12 个文字层，每个文字框最多 500 个字符。在预览中点击文字区域可以选中并拖动该层；区域重叠时，优先选中上面的层。要调整被遮住的文字，从**文字层**下拉框选择它。

展开**位置与描边**可精确设置位置。水平和垂直坐标使用画布百分比，旋转使用角度。预览获得焦点后，方向键每次移动一个百分点，按住 Shift 则移动五个百分点。**文字居中**将当前层的定位点放到画布中央。

## 横排、竖排与列方向

排版方向有**横排**、**竖排 ←**和**竖排 →**。箭头表示列的排列方向：向左时从右侧开始排下一列，向右时从左侧开始排下一列。

竖排中，换行会另起一列，较长内容也会分列。中日韩文字保持直立，拉丁文字连续片段侧转，一到两位 ASCII 数字可以横向放在一个字格内，标点随竖排列调整位置或旋转。各文字层可以使用不同方向。

预览、点击命中和 PNG 使用同一套排版。混合不同文字或输入较长内容时，结合预览调整字号和位置。

## 选择字体和角色代表色

从**字体**中选择字型，等待加载完成后导出。字体选项的用途和可用字重如下：

| 字体 | 用途与字重 |
| --- | --- |
| **YurukaStd** | 参考的 Sekai 表情工具使用的字体，提供的字型为 UB，真实字重 900。 |
| **SSFangTangTi** | Sekai 工具使用的上首方糖体，提供的字重为 400。 |
| **Roboto** | 可变字重 100–900。 |
| **思源黑体 SC／TC／JP／KR** | 各地区 CJK 无衬线字体，可变字重 100–900。 |
| **思源宋体 SC／TC／JP／KR** | 各地区 CJK 衬线字体，可变字重 200–900。 |
| **原作运行时 UI · Pretendard SemiBold** | Our Notes 运行时 UI 字体，真实字重 600。 |

支持可变字重的字体会显示**字重**控件，初始使用最粗的可用字重。固定字型沿用自身已有字重。字体覆盖的字符范围各有不同；遇到缺字时，可选择对应地区的字体。

Sekai 字体说明参考工具的文字样式，Pretendard 说明运行时 UI 的字体用途。Our Notes 原图中的表情文字已经绘制在图片里，其制作用字体尚未确认；这些选项不代表已确认原图文字使用了同一字型。

点击字体栏旁的**导入本地字体**，可从设备选择 WOFF2、WOFF、TTF 或 OTF 文件。字体按文件名加入选项，在当前页面使用，单个文件上限为 32 MiB。重新进入工具后，需要再次导入。

**文字颜色**菜单提供角色名字、头像和实际代表色色样。表情关联的角色可以提供初始颜色，也可以自由选择其他角色，或切换到**自定义颜色**。每个文字层分别保存自己的颜色选择。

## 用文字背景覆盖已有文字

为当前层展开**位置与描边 → 文字背景**，启用背景后，选择角色色或自定义背景色，并调整：

- **背景不透明度**：100% 为不透明，降低后可透出底图。
- **背景内边距**：文字实际字形及描边之外的留白，默认 0，边缘贴近文字。
- **背景圆角**：背景矩形四角的圆弧大小。

背景跟随该层的位置和旋转。将它移动到旧文字区域，结合预览检查覆盖范围。它作为文字层的矩形绘制在底图上，原始图片仍保留在下方。切换回**无背景**即可去掉矩形。

描边颜色和宽度也在这一折叠区内。预览中的选中框用于编辑定位，下载的 PNG 不包含这个框。

## 原始尺寸与降采样 PNG

**导出尺寸**列出带有实际宽高的**原始尺寸**，以及适合当前来源的较小档位。换图后，可选尺寸随来源变化。

例如，原图为 346 × 398 时，可选择 128 × 147、192 × 221、256 × 294、320 × 368 或原始 346 × 398。原图为 512 × 512 时，可以提供 128、192、256、320、384 等较小正方形尺寸，以及原始尺寸。

选择较小档位会生成实际像素更少的 PNG。图片、文字、描边和背景保持相对位置与比例。非正方形素材的**原始尺寸**保留其实际宽高和纵横比。屏幕上预览的大小不决定下载上限；把素材放大得到的派生图也不会提高有效原始分辨率。

导出按图层顺序合成所有文字层，并保留画面的透明部分。导出开始时会取得当时的图层设置。下载的文件是合成图片，不包含可重新编辑的工程图层。

## 示例：顶部短句与侧边竖排

1. 在**选择表情**中选择一个当前可用的无字素材。
2. 在第一层写一句短句，使用横排，选择字体和角色色，将它拖到角色上方。
3. 点击**新增文字**，输入侧边补充文字，切换到**竖排 ←**，再放到角色旁边。第一层保持原样。
4. 如果两个区域重叠，从**文字层**选择需要的层，用**上移一层／下移一层**调整覆盖顺序。
5. 导出**原始尺寸**作为主文件；需要小尺寸表情时，再选较小档位下载。

## 常见调整

| 现象 | 处理方法 |
| --- | --- |
| 图片加载失败 | 点击**重试**，或重新打开选择器换一张可用图片。 |
| 字体加载失败 | 重试或换一种字体，加载完成后再导出。 |
| 某个字缺失或外观不同 | 换成覆盖该文字的地区字体，或导入合适的本地字体。 |
| 文字超出画面 | 选中该层，缩小字号、调整位置，或使用**文字居中**。 |
| 点不到下方文字 | 从**文字层**选择，或调整图层顺序。 |
| 原图旧文字仍可见 | 使用无字素材，或把不透明文字背景放到旧文字区域。 |
| 菜单没有更大的尺寸 | 用**原始尺寸**取得当前来源的完整有效分辨率。 |
