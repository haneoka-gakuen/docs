Use the explicit game region in every URL. Keep 64-bit IDs as decimal strings and distinguish accountId, profileId, songId and challengeId. For stored recruitment pools use the catalog gacha entity; for archived notices use /api/v1/announcements. This page adds the live game contracts and preserves every supplied field. Read the [game API guide](/guides/game-api/) for complete workflows.
