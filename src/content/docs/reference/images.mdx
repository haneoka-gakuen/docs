Raw artwork is available from the catalog image URLs in the [media API](/servers/media/). Official chart PNG/SVG uses the [chart image API](/reference/chart-images/), and player cards use the [player resource API](/servers/records/). These endpoints generate the remaining website images. POST JSON is &#123;data, locale?, theme?, seed?&#125;. Complete nested fields are embedded in [OpenAPI](/openapi.json), and available in the [device schema](https://haneoka.org/tools/schema.json). The [image guide](/guides/image-exports/) includes payloads, local execution and state capture.
