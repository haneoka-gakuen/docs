title: Game data for websites, scripts and agents
description: Choose the right endpoint, region, ID and response format for each game-data workflow.
---

Start at `GET https://haneoka.org/api/v1`. It links the complete OpenAPI document, the release registry, each release's resource catalog, the game capability list and local calculation modules. Public reads use GET or HEAD. Errors follow `{ "error": { "code", "message", "requestId" } }`; HEAD returns the same status and headers without a body.

| Task | API |
| --- | --- |
| Game resources and rules | `/api/v1/servers/{server}/catalog`, then the returned resource, view and relation paths |
| One entity / many entities / complete collection | `/api/v1/{resource}/{id}`, repeated `id`, or cursor pagination; follow `nextCursor` until null |
| Original audio, jackets, card artwork, model files, fonts and source metadata | Use returned `/assets/`, `/runtime/` and source descriptor paths with the same release pin |
| Chart JSON, statistics and difficulty | `songs/{id}` → `difficulty[].file`; `song-meta/{id}` for every difficulty's chart and scoring metrics |
| Profile / batch profiles / favorites / profile card | `/api/v1/players/{profileId}?region={region}`, `/api/v1/players?accountId=…&region={region}`, `/api/v1/players/favorites?accountId={accountId}&region={region}`, `/api/v1/players/{profileId}/cards/{page}.png?region={region}` |
| Song / event / challenge / arena ranking | `/songs/{songId}/ranking`, `/events/{eventId}/ranking?rank=1&rank=100`, `/events/challenges/{challengeId}/ranking`, `/arena/seasons/{seasonId}/ranking?start=1&end=100` with `?region={region}` |
| Event deck / popular arena decks | `/events/{eventId}/decks/{accountId}` and `/arena/seasons/{seasonId}/songs/{songId}/decks` |
| Circle detail / exact-name search | `/circles/{circleId}` and `/circles?name=…`; optional `memberRange`, `joinRule`, `playStyle` |
| Stored recruitment pool and products | `/api/v1/gacha/{gachaId}?server={server}` → `rates`, `featured`, `drawOptions`, guarantees and selection rules |
| Product and selected pickup probabilities | `/api/v1/gacha/{gachaId}/rates?productId=…&pickupId=…&region={region}` |
| Archived game announcements | `/api/v1/announcements?server={server}&locale={locale}`; detail at `/announcements/{id}` |
| Live announcement list / detail | `/api/v1/announcements/views/live?category=ALL&region={region}` and `/announcements/{announcementId}/live` |
| Cached event schedule, cutoffs and collection state | `/api/v1/events/views/live?region={region}`, `/events/views/current`, `/events/{eventId}/snapshots`, `/events/{eventId}/snapshots/latest`, `/events/{eventId}/challenges` |
| Challenge snapshot / announcement revisions | `/events/{eventId}/challenges/{challengeId}/ranking`, `/announcements/{announcementId}/revisions` |
| Private inventory, Box, workspace and recruitment history | Existing authenticated [account synchronization endpoints](/reference/account-sync/) |
| Team search, scoring, growth and chart images | [Local computation](/guides/local-computation/) |

`server` is `jp` or `intl`; `region` is `jp`, `tw`, `en` or `kr`. `locale` selects text independently. IDs belong to one region. Keep int64 values as **strings**, including in JavaScript. A profile ID is not an account ID; a challenge ID is not a song ID. Resolve IDs from the matching catalog or prior response.

```js
import { createGameClient } from "https://haneoka.org/tools/api-client.js";
const game = createGameClient({ region: "jp" });
const ranking = await game.songRanking("100001");
for (const row of ranking.players ?? []) {
  console.log(row.playerData?.profileId, row.score, row.highScoreDeck?.cards);
}
// account IDs from a profile/list response, not public profile IDs:
const profiles = await game.profiles(accountIds);
const circle = await game.circles({ name: circleName, joinRule: "AUTO" });
```

Repeated array parameters use repeated keys: `accountId=1&accountId=2`, `rank=1&rank=100`, `pickupId=1&pickupId=2`. Lists accept up to 100 submitted values. Scalar parameters occur once. Unknown or duplicate scalar parameters return 400. The [reference](/reference/game/) specifies each required parameter and its schema.

Song ranking responses retain the returned player order. An absent row stays absent. Event snapshots can contain duplicate positions and collection parts with different timestamps; keep `stale`, `frozen`, `parts` and collection timestamps when storing them. Use `Retry-After` on 429/503 and exponential backoff. Full contracts are also available at `/api/v1/openapi.json`.

Save downloads use `GET /api/v1/players/{profileId}/save.gz?server={saveServer}` from a server or local script with `X-Game-Application-Key`. The application must already have explicit access to that save. profileId is the save’s top-level _profileId, distinct from the account/player ID. `saveServer` is `jp` or `intl`; the result is the original `application/gzip` file, at most 8 MiB. Store it as `.json.gz`; it has no HTTP `Content-Encoding`. A missing grant returns 404. Application keys stay in server configuration. For data already stored in your Haneoka account, use the account synchronization endpoints and your Haneoka session.

先读取 `GET https://haneoka.org/api/v1`。入口列出完整 OpenAPI、版本列表、各版本资源目录、游戏能力和本地计算模块。公开读取使用 GET 或 HEAD。错误沿用 `{ "error": { "code", "message", "requestId" } }`；HEAD 的状态和响应头相同，正文为空。

| 使用情形 | 接口 |
| --- | --- |
| 游戏资料与规则 | `/api/v1/servers/{server}/catalog`，再按返回的资源、视图和关系路径读取 |
| 单实体、批量实体、完整集合 | `/api/v1/{resource}/{id}`、重复 `id`、游标分页；持续读取直到 `nextCursor` 为 null |
| 原始音频、封面、卡面、模型、字体和素材描述 | 使用返回的 `/assets/`、`/runtime/` 与描述路径，沿用同一个 release |
| 原始谱面、统计和难度 | `songs/{id}` 的 `difficulty[].file`；`song-meta/{id}` 包含各难度的谱面与计分统计 |
| 玩家资料、批量资料、收藏、资料卡 | `/api/v1/players/{profileId}?region={region}`、`/api/v1/players?accountId=…&region={region}`、`/api/v1/players/favorites?accountId={accountId}&region={region}`、`/api/v1/players/{profileId}/cards/{page}.png?region={region}` |
| 歌曲榜、活动榜、挑战榜、竞技场榜 | 游戏区服下的 `/songs/{songId}/ranking`、`/events/{eventId}/ranking?rank=1&rank=100`、`/events/challenges/{challengeId}/ranking`、`/arena/seasons/{seasonId}/ranking?start=1&end=100` |
| 活动编队、竞技场热门编队 | `/events/{eventId}/decks/{accountId}`、`/arena/seasons/{seasonId}/songs/{songId}/decks` |
| 圈子详情、精确名称搜索 | `/circles/{circleId}`、`/circles?name=…`；可附加 `memberRange`、`joinRule`、`playStyle` |
| 已归档招募池及商品 | `/api/v1/gacha/{gachaId}?server={server}` 的 `rates`、`featured`、`drawOptions`、保底与自选规则 |
| 指定商品和自选 UP 的概率 | `/api/v1/gacha/{gachaId}/rates?productId=…&pickupId=…&region={region}` |
| 游戏公告归档 | `/api/v1/announcements?server={server}&locale={locale}`，详情 `/announcements/{id}` |
| 游戏内公告列表和详情 | `/api/v1/announcements/views/live?category=ALL&region={region}`、`/announcements/{announcementId}/live` |
| 活动时间、榜线与采集状态 | `/api/v1/events/views/live?region={region}`、`/events/views/current`、`/events/{eventId}/snapshots`、`/events/{eventId}/snapshots/latest`、`/events/{eventId}/challenges` |
| 挑战榜快照、公告历史版本 | `/events/{eventId}/challenges/{challengeId}/ranking`、`/announcements/{announcementId}/revisions` |
| 私有库存、Box、工作区与招募历史 | 现有的[账号同步接口](/reference/account-sync/) |
| 配队搜索、评分、成长分析与谱面图片 | [本地计算接口](/guides/local-computation/) |

`server` 为 `jp` 或 `intl`；`region` 为 `jp`、`tw`、`en`、`kr`；`locale` 单独决定文本语言。ID 只在所属区服有意义。包括 JavaScript 在内，64 位 ID 一律保留为**字符串**。公开资料 ID 与账号 ID 不同，挑战 ID 与歌曲 ID 不同，请从同区服目录或前一步响应中取值。

```js
import { createGameClient } from "https://haneoka.org/tools/api-client.js";
const game = createGameClient({ region: "jp" });
const ranking = await game.songRanking("100001");
for (const row of ranking.players ?? []) {
  console.log(row.playerData?.profileId, row.score, row.highScoreDeck?.cards);
}
// accountIds 来自资料或账号列表，不能填公开 profileId：
const profiles = await game.profiles(accountIds);
const circle = await game.circles({ name: circleName, joinRule: "AUTO" });
```

数组使用重复键：`accountId=1&accountId=2`、`rank=1&rank=100`、`pickupId=1&pickupId=2`，单次最多 100 项。标量只出现一次。未知参数和重复标量返回 400。[接口参考](/reference/game/)逐项列出必填参数与 schema。

歌曲榜保留返回的玩家顺序，缺少的行保持缺少。活动快照可能包含重复名次和不同时间的采集分段；保存时一并保留 `stale`、`frozen`、`parts` 和采集时间。429/503 遵守 `Retry-After` 并指数退避。完整游戏契约另见 `/api/v1/openapi.json`。

存档下载使用 `GET /api/v1/players/{profileId}/save.gz?server={saveServer}`，从服务端或本地脚本携带 `X-Game-Application-Key`，应用须已获得对该份存档的明确授权。profileId 是存档顶层的 _profileId，与账号／玩家 ID 分开。`saveServer` 为 `jp` 或 `intl`；结果为原始 `application/gzip` 文件，最多 8 MiB，保存为 `.json.gz`，响应没有 HTTP `Content-Encoding`。没有授权返回 404。应用密钥保存在服务端配置中。读取羽丘账号内已有的数据时，沿用账号同步接口与羽丘会话。

| 保存済みガチャと商品 | `/api/v1/gacha/{gachaId}?server={server}` の `rates`、`featured`、`drawOptions`、確定枠・選択ルール |

title: 웹사이트·스크립트·Agent의 게임 데이터 호출
description: 용도에 맞는 API, 지역, ID, 응답 형식을 선택합니다.
---

`GET https://haneoka.org/api/v1`에서 시작합니다. OpenAPI, 릴리스 목록, 리소스 카탈로그, 게임 기능 목록, 로컬 계산 모듈로 연결됩니다. 공개 읽기는 GET/HEAD를 사용합니다. 오류 형식은 `{ "error": { "code", "message", "requestId" } }`이며 HEAD에는 본문이 없습니다.

| 오디오·이미지·모델·글꼴·소재 정보 | 반환된 `/assets/`, `/runtime/`, 소재 설명 경로와 동일 release 사용 |
| 채보와 통계 | `songs/{id}`의 `difficulty[].file`, `song-meta/{id}` |
| 프로필·일괄 조회·즐겨찾기·프로필 카드 | `/api/v1/players/{profileId}?region={region}`, `/api/v1/players?accountId=…&region={region}`, `/api/v1/players/favorites?accountId={accountId}&region={region}`, `/api/v1/players/{profileId}/cards/{page}.png?region={region}` |
| 곡·이벤트·챌린지·아레나 랭킹 | `/songs/{songId}/ranking`, `/events/{eventId}/ranking?rank=1&rank=100`, `/events/challenges/{challengeId}/ranking`, `/arena/seasons/{seasonId}/ranking?start=1&end=100` |
| 이벤트 편성·인기 아레나 편성 | `/events/{eventId}/decks/{accountId}`, `/arena/seasons/{seasonId}/songs/{songId}/decks` |
| 서클 상세·이름 검색 | `/circles/{circleId}`, `/circles?name=…`; `memberRange`, `joinRule`, `playStyle` 지원 |
| 보관된 모집 풀·상품 | `/api/v1/gacha/{gachaId}?server={server}`의 `rates`, `featured`, `drawOptions`, 보장·선택 규칙 |
| 상품·선택 픽업 확률 | `/api/v1/gacha/{gachaId}/rates?productId=…&pickupId=…&region={region}` |
| 보관 공지·게임 내 공지 | `/api/v1/announcements?server={server}&locale={locale}`, `/api/v1/announcements/views/live?region={region}`, `/announcements/{announcementId}/live` |
| 이벤트 일정·컷오프·수집 상태 | `/api/v1/events/views/live?region={region}`, `/events/views/current`, `/events/{eventId}/snapshots`, `/events/{eventId}/snapshots/latest`, `/events/{eventId}/challenges` |
| 챌린지 스냅샷·공지 이전 버전 | `/events/{eventId}/challenges/{challengeId}/ranking`, `/announcements/{announcementId}/revisions` |
| 비공개 Box·인벤토리·작업 공간·모집 기록 | [계정 동기화](/reference/account-sync/) |
| 편성 검색·평가·성장 분석·채보 이미지 | [로컬 계산](/guides/local-computation/) |

server는 jp/intl, region은 jp/tw/en/kr, locale은 표시 언어입니다. 64비트 ID는 문자열로 유지하세요. profileId와 accountId, challengeId와 songId는 서로 다르며 ID는 같은 지역에서 가져와야 합니다.

```js
import { createGameClient } from "https://haneoka.org/tools/api-client.js";
const game = createGameClient({ region: "jp" });
const ranking = await game.songRanking("100001");
for (const row of ranking.players ?? []) console.log(row.playerData?.profileId, row.score);
const profiles = await game.profiles(accountIds);
const circle = await game.circles({ name: circleName, joinRule: "AUTO" });
```

배열은 `accountId=1&accountId=2`, `rank=1&rank=100`, `pickupId=1&pickupId=2`처럼 키를 반복하며 최대 100개입니다. 스칼라 중복과 알 수 없는 매개변수는 400입니다. 필수 값은 [참고 문서](/reference/game/)에서 확인하세요. 곡 랭킹은 응답 순서를 유지하고 누락 순위를 0으로 채우지 않습니다. 이벤트 스냅샷은 `stale`, `frozen`, `parts`, 수집 시각을 함께 저장합니다. 429/503은 `Retry-After`와 지수 백오프를 따르세요. 게임 OpenAPI는 `/api/v1/openapi.json`입니다.

저장 파일 다운로드는 `GET /api/v1/players/{profileId}/save.gz?server={saveServer}`입니다. 서버나 로컬 스크립트에서 `X-Game-Application-Key`를 보내며 앱은 해당 저장 파일에 대한 명시적 권한이 있어야 합니다. profileId는 저장 파일 최상위 _profileId이며 계정 ID와 다릅니다. saveServer는 jp/intl입니다. 최대 8 MiB의 `application/gzip`을 `.json.gz`로 저장하세요. HTTP `Content-Encoding`은 없습니다. 권한이 없으면 404입니다. 키는 서버에 저장합니다. 하네오카 계정에 저장된 데이터는 기존 동기화 API와 하네오카 세션을 사용합니다.
